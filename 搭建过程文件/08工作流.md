# 初版线圈电流波形工作流

## 1. 工作流定位

本工作流只完成“初版波形生成”：把一组 SPARC 背景下可实现的实验目标，转化为 CS / PF / Div / VS 的候选线圈电流波形。

不追求最终工程定型，不使用 Bluemira、TORAX 等复杂集成仿真；只采用直接平衡计算、工程约束检查和分阶段物理验证。

---

## 2. 假定实验目标与初始输入

选取一组保守、适合初版设计的 SPARC 类放电目标：

| 输入类别 | 设定值 | 作用 |
|---|---:|---|
| 背景环向场 `B_t` | 12 T | TF 给定常值，不参与主波形优化 |
| 平顶等离子体电流 `I_p,flat` | 8.7 MA | 决定 CS 伏秒需求和 PF 平衡场需求 |
| 击穿时间 | 0–0.05 s | 形成初始等离子体 |
| 电流爬升时间 | 0.05–2.0 s | `I_p` 从种子电流升至平顶电流 |
| 平顶时间 | 2.0–3.0 s | 维持目标电流和位形 |
| 击穿位置 | `R = 1.85 m, Z = 0` | PF3 / PF4 形成低极向场区的目标点 |
| 平顶主半径 `R_0` | 1.85 m | PF3 / PF4 控制整体径向平衡 |
| 小半径 `a` | 0.55 m | PF1 / PF2 成形目标 |
| 拉长比 `κ` | 1.8 | PF1 / PF2 / PF3 逐步建立 |
| 三角形变 `δ` | 0.35 | PF2 / PF3 后期建立 |
| 平顶位形 | 单零偏滤器位形 | PF3 / PF4 + Div 维持 X 点和打击点 |
| 线圈约束 | 电流、变化率、伏秒不超限 | 每轮波形生成后的硬检查 |

这些输入被整理成三类数据：

1. **时间目标**：三阶段分界点和 `I_p(t)` 目标轨迹；
2. **位形目标**：`R_0(t)、a(t)、κ(t)、δ(t)、X-point(t)`；
3. **工程约束**：CS 伏秒、电流上限、PF 电流上限、线圈变化率上限。

---

## 3. 信息传播主线

初始输入不是直接变成线圈电流，而是沿两条主线传播：

```text
实验目标
  ├─ 电流驱动主线：I_p(t) → loop voltage → CS 电流变化率 → I_CS(t)
  └─ 位形控制主线：R/a/κ/δ/X-point → 平衡场需求 → PF 电流 → I_PF(t)
```

两条主线先解耦生成初版波形，再用直接平衡计算做一致性校验。

---

## 4. 阶段 1：Breakdown 击穿

### 4.1 输入如何传播

| 输入信息 | 传播到 | 线圈动作 |
|---|---|---|
| 击穿时间 0–0.05 s | CS 感应电压需求 | CS 从预充磁状态快速变化，产生 loop voltage |
| 击穿点 `R=1.85 m, Z=0` | PF 零场目标 | PF3 / PF4 预置电流，使击穿点附近 `B_R、B_Z` 尽量小 |
| 背景 `B_t=12 T` | TF 常值 | TF 保持背景环向场 |
| 初始场线不撞壁 | PF 局部修正 | PF1 / PF2 给小修正电流 |

### 4.2 输出波形特征

- `I_CS1/2/3(t)`：从预充磁电流开始快速摆动；
- `I_PF3/4(t)`：击穿前已到达零场预置值，击穿期间尽量平稳；
- `I_PF1/2(t)`：小幅辅助修正；
- `I_Div(t)=0`，`I_VS(t)=0` 或只给裕度。

### 4.3 验证

只检查三件事：

1. 击穿点附近极向场是否足够低；
2. CS 变化率是否能提供足够 loop voltage；
3. 初始闭合磁面或可捕获场结构是否合理。

---

## 5. 阶段 2：Ramp-up 电流爬升

### 5.1 输入如何传播

| 输入信息 | 传播到 | 线圈动作 |
|---|---|---|
| `I_p: seed → 8.7 MA` | loop voltage 和伏秒消耗 | CS 持续平滑 swing，驱动电流爬升 |
| `R_0=1.85 m` | 径向力平衡 | PF3 / PF4 随 `I_p` 增大调整垂直场 |
| `a、κ、δ` 从初始值过渡到目标值 | 形状控制 | PF1 / PF2 / PF3 平滑变化，逐步拉长并建立三角形变 |
| 单零偏滤器目标 | X 点形成 | PF3 / PF4 在爬升后段引入上下差分趋势 |
| 平顶打击点准备 | Div 设定 | Div 在爬升末期缓慢接近平顶工作点 |

### 5.2 输出波形特征

- `I_CS(t)`：大幅、单调或近似单调变化，斜率由 `dI_p/dt` 决定；
- `I_PF4(t)`：主要跟随 `I_p` 增大，维持径向平衡；
- `I_PF3(t)`：同时控制位置和 X 点形成趋势；
- `I_PF1/2(t)`：从近圆截面逐步过渡到目标 `κ、δ`；
- `I_Div(t)`：只在后段慢慢进入工作点；
- `I_VS(t)`：不生成快速波形，只检查稳定裕度。

### 5.3 验证

采用直接 Grad-Shafranov 平衡计算或等效快速平衡程序，在若干时间片检查：

1. `I_p(t)` 是否按目标爬升；
2. 主半径是否保持在允许范围；
3. 拉长比和三角形变是否平滑接近目标；
4. PF / CS 电流和变化率是否超限；
5. CS 伏秒是否仍保留平顶裕度。

---

## 6. 阶段 3：Flat-top 平顶

### 6.1 输入如何传播

| 输入信息 | 传播到 | 线圈动作 |
|---|---|---|
| `I_p,flat = 8.7 MA` | 维持电压和剩余伏秒 | CS 缓慢变化，维持等离子体电流 |
| `R_0、a、κ、δ` 固定目标 | 平衡和边界控制 | PF1–PF4 进入近稳态工作点 |
| 单零偏滤器位形 | X 点和打击点 | PF3 / PF4 维持 X 点，Div 微调打击点 |
| 垂直稳定需求 | 控制裕度 | VS 不设定离线快速波形，只预留反馈余量 |

### 6.2 输出波形特征

- `I_CS(t)`：慢速变化，重点是剩余伏秒够用；
- `I_PF1/2/3/4(t)`：接近平稳，只允许小幅慢调；
- `I_Div1/2(t)`：给定平顶工作点，必要时可加小幅低频扫描；
- `I_VS(t)`：基准为 0 或小偏置，输出允许反馈范围；
- `I_TF(t)`：继续视为常值背景。

### 6.3 验证

1. 平衡边界是否接近目标 `R_0、a、κ、δ`；
2. X 点和打击点位置是否合理；
3. CS 剩余伏秒能否覆盖平顶时间；
4. PF 和 Div 是否仍有调节余量；
5. VS 是否留有垂直稳定控制裕度。

---

## 7. 初版波形生成顺序

1. **生成目标轨迹**：构造 `I_p(t)`、`R_0(t)`、`a(t)`、`κ(t)`、`δ(t)`、`X-point(t)`。
2. **生成 CS 初版波形**：由 `I_p(t)` 估算 loop voltage 和伏秒需求，反推 `I_CS1/2/3(t)`。
3. **生成 PF 初版波形**：由每个时间片的目标位形，用直接平衡计算求 `I_PF1/2/3/4(t)`。
4. **加入 Div / VS 简化处理**：Div 只在平顶附近给工作点；VS 只输出基准和裕度。
5. **平滑处理**：对所有线圈电流做斜率限制和样条平滑，避免不合理突变。
6. **约束检查**：检查电流上限、变化率上限、CS 伏秒、PF 控制余量。
7. **物理检查**：检查击穿零场、爬升平衡、平顶形状和 X 点。
8. **输出候选波形表**：形成 `time, I_CS1, I_CS2, I_CS3, I_PF1, I_PF2, I_PF3, I_PF4, I_Div1, I_Div2, I_VS`。

---

## 8. 最终输出

本工作流最终输出的是一组“可评审的初版波形”，而不是最优波形：

- CS 波形说明 `I_p` 如何被拉升并维持；
- PF 波形说明位形如何从击穿零场过渡到平顶偏滤器构型；
- Div 波形说明打击点如何在平顶被微调；
- VS 只给反馈裕度；
- 每个阶段都附带约束检查和物理合理性判断。

核心逻辑是：

```text
实验目标 → 时间轨迹/位形轨迹 → CS 与 PF 初版波形 → 直接平衡校验 → 约束修正 → 实验波形表
```
