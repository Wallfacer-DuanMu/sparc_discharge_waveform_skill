升级后新流程（保持现有函数接口，内部替换物理模型）：

text
1. 生成时间轴（不变）
2. 用真空环电感 L0 和击穿电阻 Rp 建立 Ip(t) 与 V_loop(t) 的关系
   → 从目标 Ip_seed_MA 和爬升时间反推需要的 V_loop(t)
3. 用 Biot-Savart 计算击穿点处各 PF 线圈产生的磁场
   → 调整 PF3/PF4 初始电流使 B_R≈0, B_Z≈0
4. 用互感方程计算所需 CS 总 dI/dt
   → 分配至 CS1/CS2/CS3（可仍用比例，但总幅度由物理公式决定）
5. 积分得 CS 电流波形，检查 dI/dt 限幅
6. 更新 Ip(t) 与 CS 自洽性（简单迭代一次）
7. 输出波形 + 物理验证（零场误差、伏秒、电压跟踪）

def generate_cs_swing_physical(times, ip_target, coils, M_cs=1.5e-6, L0=...):
    """根据目标 Ip(t) 反推需要的 CS 电流变化率"""
    dt_array = np.diff(times)
    Ip = np.array(ip_target)
    dIp_dt = np.gradient(Ip, times)
    # 击穿初期 V_loop = L0 * dIp/dt + Rp * Ip
    Rp = 0.1  # 欧姆，可随时间衰减
    V_loop_needed = L0 * dIp_dt + Rp * Ip
    # CS 提供的电压: V_loop = - M_cs * dIcs/dt (忽略 PF 变化，因 PF 慢变)
    dIcs_dt_needed = -V_loop_needed / M_cs
    # 积分得 Ics(t)，检查 dI/dt 限幅
    Ics = integrate(dIcs_dt_needed, I0=coils['CS1']['I0_MA']*1e6)  # 安培
    return Ics / 1e6  # 转 MA

def estimate_zero_field_error(pf_end_state):
    Br, Bz = compute_breakdown_B(pf_end_state)

四、保持工程简洁的关键原则
常数化近似：互感 M_cs、位置矩阵都写成固定值（可从 config 读取，但默认内置），不调用复杂开源场求解器。

忽略 PF 变化对环电压的影响：因为 PF 在击穿阶段变化很慢（dI/dt 远小于 CS），可先忽略，后续迭代修正。

等离子体参数固定：击穿阶段只用一个等效电感 L0 和电阻 Rp，不随温度变化。

不迭代自由边界：只用击穿点场条件确定 PF 预置，不计算全局平衡。

保持函数接口不变：generate_breakdown 的输入输出结构不变，只替换内部实现。

这样升级后，第一阶段就有真实的物理公式支撑，但代码增量不超过 150 行。
