# 01 项目摘要

## 1. 项目摘要

本项目面向“托卡马克标准放电线圈电流波形设计”这一学生作业任务，目标是封装一个专用 Skill：以 SPARC 为参考装置，在给定目标放电结果和简化装置约束的前提下，生成 `Breakdown`、`Ramp-up`、`Flat-top` 三个阶段的候选线圈电流波形。

本项目不追求完整工程定型，也不追求最优波形。它更关注一条清晰、自洽、可复查的推演链路：

1. 把放电过程拆成三个物理阶段；
2. 把每个阶段打包成一个可执行的计算工作包；
3. 在每个工作包中明确 CS、PF、Div、VS、TF 的职责；
4. 输出候选波形、约束检查、风险提示和下一轮修正建议。

最终结果是一个离线波形设计助手，而不是实时控制系统。它服务于实验前准备：把“希望得到的目标放电”转化为“可评审、可修改、可迭代的预设线圈波形方案”。

---

## 2. Skill 定位

本 Skill 的定位是：**SPARC 参考装置下的三阶段离线线圈波形规划助手**。

它接收的主要输入包括：

- 目标平顶等离子体电流 `Ip_flat`；
- 放电三阶段时间安排；
- 目标位形参数，例如 `R/a/κ/δ/X-point` 的演化趋势；
- 简化 SPARC 装置参数与线圈约束；
- 各线圈组的电流上限、变化率上限和伏秒约束。

它输出的主要结果包括：

- `I_CS1(t)`、`I_CS2(t)`、`I_CS3(t)`；
- `I_PF1(t)`、`I_PF2(t)`、`I_PF3(t)`、`I_PF4(t)`；
- 简化的 `I_Div1(t)`、`I_Div2(t)`、`I_VS(t)`、`I_TF(t)` 说明；
- 电流限幅、变化率、CS 伏秒、平滑性、击穿零场、位形趋势等检查结果；
- 不满足约束时的修正建议。

本 Skill 的边界也很明确：

- `TF` 作为固定背景环向场，不作为主优化变量；
- `VS` 属于实时反馈系统，本项目只给基准和裕度；
- `Div` 只在 ramp-up 后段和平顶阶段参与偏滤器细调；
- 初版不做完整自由边界平衡求解，只做工程量级、趋势一致性和约束可行性验证。

## 3. 总体方法：物理三阶段与操作三阶段

真实托卡马克放电可以按物理过程分为三个阶段：

1. **Breakdown 击穿**：形成初始等离子体和种子电流；
2. **Ramp-up 电流爬升**：把 `Ip` 从种子电流升到目标平顶电流，同时逐步成形；
3. **Flat-top 平顶稳态**：维持目标 `Ip`、边界、X 点和偏滤器构型。

本 Skill 直接把这三个物理阶段转化为三个操作工作包：

| 物理阶段 | 操作工作包 | 核心任务 | 主要输出 |
|---|---|---|---|
| Breakdown | `stage_1_breakdown` | CS 提供击穿电压，PF3/PF4 形成击穿零场 | 初始 CS swing、PF 零场预置、击穿可行性检查 |
| Ramp-up | `stage_2_rampup` | CS 驱动 `Ip` 上升，PF1-4 逐步成形并保持平衡 | 升流波形、位形演化波形、伏秒与限幅检查 |
| Flat-top | `stage_3_flattop` | CS 维持电流，PF 维持位形，Div 微调偏滤器 | 平顶工作点、剩余伏秒、边界/X 点/打击点检查 |

这样做的核心好处是：每个阶段既对应明确的物理目标，又对应明确的输入、计算、输出和验证项。AI 或读者不需要一次性理解完整复杂装置，而是可以沿着三个工作包逐段阅读、逐段生成、逐段检查。

## 4. 线圈行为如何“包”进阶段计算

本项目的关键设计思想是：**不是先孤立地设计每个线圈，而是先确定阶段目标，再把线圈职责打包进该阶段的计算流程中。**

也就是说，每个阶段工作包都包含四类内容：

1. 阶段物理目标；
2. 该阶段需要重点使用的线圈组；
3. 由目标反推线圈波形的简化模型；
4. 对该阶段波形的约束检查。

### 4.1 Breakdown 包

Breakdown 包关注“能不能可靠击穿”。

- `CS1/CS2/CS3`：从预充磁状态开始变化，产生足够 loop voltage；
- `PF3/PF4`：在击穿区附近形成低 `B_R/B_Z` 的零场区；
- `PF1/PF2`：只做局部场结构修正；
- `Div/VS`：不参与主设计；
- `TF`：作为固定背景场。

本阶段输出的不是完整平顶位形，而是“击穿能否发生、初始等离子体能否被捕获”的候选波形。

### 4.2 Ramp-up 包

Ramp-up 包关注“能不能把电流平滑升上去，并逐步形成目标形状”。

它采用两条弱耦合主线：

- 电流驱动线：`目标 Ip(t)` → `所需 loop voltage` → `CS dI/dt` → `CS 波形`；
- 位形控制线：`目标 R/a/κ/δ/X-point 演化` → `PF 场趋势` → `PF1/PF2/PF3/PF4 波形`。

其中：

- `CS` 负责 `Ip` 爬升和伏秒管理；
- `PF4/PF3` 负责整体平衡、主半径和位置控制；
- `PF1/PF2` 负责边界、拉长比、三角形变和 X 点趋势；
- `Div` 只在后段缓慢接近平顶设定；
- `VS` 只检查是否保留稳定裕度。

### 4.3 Flat-top 包

Flat-top 包关注“能不能维持目标放电状态”。

- `CS`：缓慢变化，维持感应电流并检查剩余伏秒；
- `PF1/PF2/PF3/PF4`：维持目标边界、平衡、X 点和偏滤器入口位形；
- `Div1/Div2`：给定平顶工作点或小幅扫描，用于打击点细调；
- `VS`：不生成快速反馈波形，只保留实时稳定裕度；
- `TF`：继续作为背景场。

本阶段重点不是重新大幅调整波形，而是检查平顶工作点是否稳定、平滑、留有裕度。

## 5. 本项目的最小闭环

本 Skill 的最小闭环可以概括为：

```text
目标放电需求
  → 三阶段目标拆解
  → 每阶段线圈职责分配
  → CS 电流驱动波形 + PF 位形控制波形
  → Div/VS/TF 简化处理
  → 电流、变化率、伏秒、位形趋势检查
  → 输出候选方案与修正建议
```

这个闭环保证了项目思路完整：既能说明为什么要这样设计波形，也能说明每类线圈在每个阶段承担什么任务，以及生成结果如何被检查。

---

## 6. 一句话口径

本项目将 SPARC 放电波形设计简化为三个阶段工作包：`Breakdown` 中用 CS 触发击穿、PF3/PF4 做零场；`Ramp-up` 中用 CS 拉升 `Ip`、PF1-4 逐步成形和平衡；`Flat-top` 中用 CS 保持电流、PF 维持位形、Div 微调打击点，VS 和 TF 分别作为稳定裕度与固定背景场处理。
