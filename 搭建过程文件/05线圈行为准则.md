# 三阶段线圈行为表：各类线圈在 Breakdown / Ramp-up / Flat-top 中做什么

## 0. 对 `04磁场线圈关系.md` 的检查结论

你在 `04磁场线圈关系.md` 中对线圈对象的划分总体是正确的，适合作为个人作业工程的线圈对象基础。

可以保留的核心划分是：

1. **TF 环向场线圈**：提供主环向磁场，通常作为背景磁场，不作为本作业的主要波形优化对象。
2. **CS 中心螺线管**：通过磁通变化产生环向电压，驱动等离子体电流，是 `Ip` 启动和爬升的核心线圈。
3. **PF 极向场线圈**：控制等离子体位置、形状、X 点和偏滤器位形，是位形控制的核心线圈。
4. **Div 偏滤器线圈**：主要用于打击点位置和偏滤器区域磁场细调。
5. **VS 垂直稳定线圈**：主要用于快速反馈稳定，离线波形设计中只需要给出基准和裕度。

需要稍微修正或注意的地方：

- **PF3 不宜只写成“控制垂直位置和底部 X 点”**。更稳妥的说法是：PF3 参与整体位形、X 点位置、等离子体上下/径向平衡控制。具体负责上部还是下部 X 点，取决于上下线圈电流组合和目标构型。
- **Div 线圈在个人作业工程中不建议作为主优化对象**。它可以被处理成平顶阶段的局部修正线圈，而不是三阶段都参与复杂求解。
- **VS 不建议纳入离线主波形求解**。它更像实时反馈执行器，个人作业中可以只输出“预留控制裕度”或“基准电流为 0 / 小偏置”。
- **CS 与 PF 可以先解耦处理**：CS 主要负责 `目标 Ip -> loop voltage -> CS 电流`；PF 主要负责 `目标位形 -> PF 电流`。这种简化适合本作业。

因此，后续本工程建议采用如下精简线圈对象：

| 层级 | 线圈对象 | 是否作为主波形对象 | 处理方式 |
|---|---|---:|---|
| 背景场 | TF | 否 | 给定常值或慢速升场，不重点设计 |
| 电流驱动 | CS1 / CS2 / CS3 上下对 | 是 | 生成三阶段主波形，重点检查伏秒数、电流限幅、变化率 |
| 位形控制 | PF1 / PF2 / PF3 / PF4 上下对 | 是 | 生成三阶段位形控制波形，重点检查电流限幅、形状目标、平衡裕度 |
| 偏滤器细调 | Div1 / Div2 | 弱参与 | 主要在平顶阶段调整打击点；前两阶段可简化为 0 或缓慢过渡 |
| 快速稳定 | VS | 否 | 离线只给基准值和控制裕度，不设计快速反馈细节 |

# 1. 线圈对象统一

为了降低个人作业工程复杂度，本项目不把每个物理线圈都当作完全独立对象，而是按“功能组”设计波形。

## 1.1 主波形对象

本作业重点生成以下线圈组的电流波形：

| 线圈组 | 包含部件 | 主要职责 | 在本作业中的角色 |
|---|---|---|---|
| CS 组 | CS1_U/L、CS2_U/L、CS3_U/L | 产生环向电压，驱动 `Ip` | 主波形对象 |
| 内侧/成形 PF 组 | PF1_U/L、PF2_U/L | 控制上/下边界、拉长比、X 点趋势 | 主波形对象 |
| 外侧/平衡 PF 组 | PF3_U/L、PF4_U/L | 控制径向平衡、垂直场、击穿零场、整体位形 | 主波形对象 |

## 1.2 次要或简化对象

| 线圈组 | 包含部件 | 简化处理 |
|---|---|---|
| TF | TF coils | 作为已给定背景磁场，不参与三阶段主波形求解 |
| Div | Div1、Div2 | 平顶阶段用于偏滤器打击点修正，前两阶段可设为 0 或跟随 PF 缓慢变化 |
| VS | VS pair | 不设计快速波形，只预留反馈裕度；离线基准可设为 0 或小偏置 |

## 1.3 上下线圈的简化假设

个人作业工程中建议先采用上下对称假设：

| 线圈对 | 简化关系 |
|---|---|
| CS1_U / CS1_L | 同组或近似同波形 |
| CS2_U / CS2_L | 同组或近似同波形 |
| CS3_U / CS3_L | 同组或近似同波形 |
| PF1_U / PF1_L | 击穿与早期爬升可对称，平顶可允许小差分 |
| PF2_U / PF2_L | 击穿与早期爬升可对称，平顶可允许小差分 |
| PF3_U / PF3_L | 可用于上下位形和 X 点调节，后期允许差分 |
| PF4_U / PF4_L | 主要提供整体平衡和击穿零场，优先对称处理 |

也就是说，初版不是直接求十几个完全独立波形，而是先求：

- `I_CS1(t)`、`I_CS2(t)`、`I_CS3(t)`；
- `I_PF1(t)`、`I_PF2(t)`、`I_PF3(t)`、`I_PF4(t)`；
- 必要时再给 PF 上下线圈加入小的差分修正。

# 2. 三阶段总览

本作业只考虑三个主要阶段：

1. **Breakdown 击穿阶段**：从真空和预充气状态形成初始等离子体。
2. **Ramp-up 电流爬升阶段**：把等离子体电流从种子电流升到目标平顶电流，同时逐步成形。
3. **Flat-top 平顶阶段**：维持目标 `Ip`、位形、X 点和偏滤器构型。

三阶段中，各线圈的主次关系如下：

| 阶段 | 最关键线圈 | 辅助线圈 | 简化线圈 |
|---|---|---|---|
| Breakdown | CS、PF4、PF3 | PF1、PF2 | Div、VS、TF |
| Ramp-up | CS、PF1、PF2、PF3、PF4 | Div | VS、TF |
| Flat-top | PF1、PF2、PF3、PF4、CS | Div、VS | TF |

# 3. Breakdown 阶段：击穿阶段线圈行为

## 3.1 阶段目标

击穿阶段的目标不是获得最终位形，而是：

1. 在预定位置产生可靠击穿；
2. 形成初始等离子体电流；
3. 建立可捕获的初始磁场结构；
4. 避免初生等离子体立即撞壁或丢失。

核心物理目标可以简化为：

- CS 提供足够的环向电压；
- PF 在击穿区附近制造低极向场或近似零场区；
- TF 提供背景环向磁场。

## 3.2 Breakdown 阶段各线圈职责

| 线圈类型 | 具体线圈/部件 | 这个阶段要干什么 | 波形特征 | 本作业处理方式 |
|---|---|---|---|---|
| TF | TF coils | 提供背景环向磁场 `B_t`，保证粒子有基本环向约束 | 放电前已升到目标值或接近目标值，阶段内近似不变 | 作为输入常量，不生成复杂波形 |
| CS | CS1、CS2、CS3 | 从预充磁状态开始变化，产生 loop voltage，触发气体击穿并驱动初始 `Ip` | 起始电流较大；击穿时有明显 `dI/dt`；方向由目标感应电压决定 | 主波形对象；先根据目标 loop voltage 反推 CS 变化率 |
| PF 外层 | PF4_U/L、PF3_U/L | 在击穿点附近形成低 `B_R`、低 `B_Z` 的零场区；同时提供初始径向/垂直平衡 | 击穿前预置到某一电流；击穿短时间内尽量平稳 | 主波形对象；优先用于击穿零场设计 |
| PF 内层 | PF1_U/L、PF2_U/L | 辅助调整击穿区局部磁场，避免初始场线过快连到壁 | 小到中等电流；变化较缓 | 可作为修正量，不作为击穿主执行器 |
| Div | Div1、Div2 | 击穿阶段通常不需要打击点扫描 | 可为 0 或固定小偏置 | 简化为不参与 |
| VS | VS pair | 击穿阶段不承担离线主波形任务 | 快速反馈系统待命 | 只预留裕度，不设计波形 |

## 3.3 Breakdown 阶段重点设计对象

本阶段真正需要设计的是：

1. `CS1/CS2/CS3` 的初始预充磁电流和击穿期间变化率；
2. `PF3/PF4` 的预置电流，用于形成击穿零场区；
3. `PF1/PF2` 的小修正电流，用于改善初始场结构。

可以暂时不设计的是：

- Div 高频调制；
- VS 快速反馈；
- TF 动态变化。

# 4. Ramp-up 阶段：电流爬升阶段线圈行为

## 4.1 阶段目标

电流爬升阶段的目标是：

1. 将等离子体电流从初始种子电流升到目标平顶电流；
2. 在升流过程中保持等离子体位置稳定；
3. 让等离子体尺寸逐渐扩大；
4. 逐步形成目标形状，例如拉长、三角形变和 X 点；
5. 控制 CS 伏秒消耗，不提前耗尽磁通。

这一阶段是 CS 和 PF 同时强参与的阶段。

## 4.2 Ramp-up 阶段各线圈职责

| 线圈类型 | 具体线圈/部件 | 这个阶段要干什么 | 波形特征 | 本作业处理方式 |
|---|---|---|---|---|
| TF | TF coils | 维持背景环向磁场 | 基本恒定 | 作为输入常量 |
| CS | CS1、CS2、CS3 | 持续提供感应电压，使 `Ip` 按目标轨迹上升；管理伏秒消耗 | 大摆幅、相对平滑；变化率受电源电压限制 | 主波形对象；由 `Ip(t)` 和 loop voltage 需求推导 |
| PF 外层 | PF4_U/L | 提供主要垂直场和整体径向平衡；随着 `Ip` 增大调整平衡场 | 电流随 `Ip` 增大而明显变化；变化较平滑 | 主波形对象；用于整体平衡和等离子体主半径控制 |
| PF 外层/中间 | PF3_U/L | 参与垂直场、X 点位置、上下位形和径向位置控制 | 中等幅度变化；后期可能出现上下差分 | 主波形对象；用于从圆截面向偏滤器位形过渡 |
| PF 内层 | PF1_U/L | 控制上/下边界、顶部或内侧局部形状 | 中等电流，平滑变化 | 主波形对象；用于形状精细控制 |
| PF 内层 | PF2_U/L | 控制拉长比、三角形变、X 点趋势和边界形状 | 中等电流，平滑变化 | 主波形对象；用于成形和 X 点建立 |
| Div | Div1、Div2 | 接近爬升末期时可参与偏滤器区磁场准备 | 小幅缓慢过渡 | 简化为在 ramp-up 后段逐渐接近平顶值 |
| VS | VS pair | 等离子体逐渐拉长后，垂直不稳定风险增加；VS 作为反馈执行器待命 | 离线不预设快速反馈 | 只检查是否留有电流裕度 |

## 4.3 Ramp-up 阶段重点设计对象

本阶段真正需要设计的是：

1. `CS1/CS2/CS3`：决定 `Ip` 能不能按目标斜率升上去；
2. `PF4`：提供随 `Ip` 增大的整体平衡场；
3. `PF3`：控制等离子体位置、上下位形和 X 点形成趋势；
4. `PF1/PF2`：负责从简单初始截面逐渐过渡到目标拉长和三角形变；
5. `Div`：只在 ramp-up 后期缓慢进入工作点，不做快速调制；
6. `VS`：只作为稳定性裕度，不输出复杂离线波形。

## 4.4 Ramp-up 阶段可以采用的简化逻辑

个人作业工程中，可以把 ramp-up 阶段简化成两条主线：

### 主线 A：电流驱动

`目标 Ip(t)` → `需要的 loop voltage` → `CS 电流变化率` → `CS1/CS2/CS3 波形`

### 主线 B：位形控制

`目标 R/a/κ/δ/X-point 演化` → `需要的 PF 场` → `PF1/PF2/PF3/PF4 波形`

其中 CS 和 PF 不做完全耦合的非线性求解，只做迭代校验：

- CS 是否超电流/电压/伏秒；
- PF 是否超电流/变化率；
- 等离子体位置和形状是否大致合理。

# 5. Flat-top 阶段：平顶阶段线圈行为

## 5.1 阶段目标

平顶阶段的目标是：

1. 维持目标等离子体电流 `Ip_flat`；
2. 维持目标形状，包括主半径、小半径、拉长比、三角形变；
3. 维持 X 点和偏滤器位形；
4. 维持足够的控制裕度；
5. 避免 CS 磁通耗尽，保证平顶持续时间。

## 5.2 Flat-top 阶段各线圈职责

| 线圈类型 | 具体线圈/部件 | 这个阶段要干什么 | 波形特征 | 本作业处理方式 |
|---|---|---|---|---|
| TF | TF coils | 维持背景环向磁场 | 恒定 | 作为输入常量 |
| CS | CS1、CS2、CS3 | 维持感应电流所需的剩余 loop voltage；同时保留磁通裕度 | 变化比 ramp-up 慢；理想情况下接近缓慢变化 | 主波形对象；重点检查剩余伏秒和平顶时长 |
| PF 外层 | PF4_U/L | 维持整体径向平衡和主半径位置 | 接近平稳，小幅慢调 | 主波形对象；维持整体平衡 |
| PF 外层/中间 | PF3_U/L | 维持 X 点、上下位形、垂直位置和偏滤器入口磁场 | 接近平稳，可允许小差分 | 主波形对象；维持偏滤器位形和位置 |
| PF 内层 | PF1_U/L | 维持上/下边界和局部形状 | 接近平稳，小幅慢调 | 主波形对象；维持边界形状 |
| PF 内层 | PF2_U/L | 维持拉长比、三角形变和 X 点相关形状 | 接近平稳，小幅慢调 | 主波形对象；维持目标 κ、δ、X-point |
| Div | Div1、Div2 | 调整偏滤器打击点位置，必要时进行小幅摆动 | 小幅调制，可比 PF 更灵活 | 本作业可输出平顶设定值或简单小幅扫描，不做复杂热负荷优化 |
| VS | VS pair | 抑制垂直位移事件，实时稳定高拉长等离子体 | 快速反馈，高频响应 | 不做离线详细波形；只给基准和裕度 |

## 5.3 Flat-top 阶段重点设计对象

本阶段真正需要设计的是：

1. `CS1/CS2/CS3` 的缓慢变化，保证平顶电流维持且伏秒不耗尽；
2. `PF1/PF2/PF3/PF4` 的平顶工作点，保证目标形状和 X 点；
3. `Div1/Div2` 的平顶工作点，用于打击点位置微调；
4. `VS` 的电流裕度，而不是具体反馈波形。

# 6. 三阶段-线圈行为总表

下面是本作业最核心的结构化结果。

| 阶段 | CS1/CS2/CS3 | PF1/PF2 | PF3/PF4 | Div1/Div2 | VS | TF |
|---|---|---|---|---|---|---|
| Breakdown | 预充磁后快速变化，产生 loop voltage，触发击穿和初始 `Ip` | 辅助修正击穿区局部场结构 | 主要负责击穿零场区和初始平衡场 | 不参与或固定为 0 | 待命，只留裕度 | 背景场，近似恒定 |
| Ramp-up | 持续 swing，驱动 `Ip` 从种子值升到目标值，控制伏秒消耗 | 逐步成形，控制拉长比、边界、三角形变和 X 点趋势 | 随 `Ip` 增大提供平衡场，控制主半径、垂直场和 X 点形成 | 后期缓慢接近平顶设定值 | 待命，检查裕度 | 背景场，近似恒定 |
| Flat-top | 缓慢变化，维持电流并检查剩余伏秒 | 维持目标形状、边界、拉长比和三角形变 | 维持整体平衡、X 点、偏滤器入口和位置 | 调整打击点，可做小幅扫描 | 实时反馈对象，离线只给基准和裕度 | 背景场，恒定 |

# 7. 每类线圈在三个阶段的简化波形形态

## 7.1 CS 组

| 阶段 | 波形形态 | 设计重点 |
|---|---|---|
| Breakdown | 从预充磁值开始快速变化 | loop voltage 是否足够 |
| Ramp-up | 大幅、平滑、持续变化 | `Ip` 爬升斜率和伏秒消耗 |
| Flat-top | 慢速变化或接近平缓 | 维持电流和平顶持续时间 |

## 7.2 PF1 / PF2

| 阶段 | 波形形态 | 设计重点 |
|---|---|---|
| Breakdown | 小到中等预置电流 | 辅助击穿 null 和初始场线结构 |
| Ramp-up | 随形状演化平滑变化 | 拉长比、三角形变、边界成形 |
| Flat-top | 接近平稳，小幅慢调 | 维持目标形状 |

## 7.3 PF3 / PF4

| 阶段 | 波形形态 | 设计重点 |
|---|---|---|
| Breakdown | 预置到击穿零场配置 | 击穿区低 `B_R/B_Z` 和初始平衡 |
| Ramp-up | 随 `Ip` 明显变化 | 主半径、径向平衡、垂直场、X 点形成 |
| Flat-top | 接近平稳，可小幅修正 | 整体平衡、X 点和偏滤器入口位形 |

## 7.4 Div 组

| 阶段 | 波形形态 | 设计重点 |
|---|---|---|
| Breakdown | 0 或固定值 | 不作为击穿对象 |
| Ramp-up | 后期缓慢接近平顶值 | 为偏滤器位形做准备 |
| Flat-top | 小幅调制或固定工作点 | 打击点位置控制 |

## 7.5 VS 组

| 阶段 | 波形形态 | 设计重点 |
|---|---|---|
| Breakdown | 0 或待命 | 不参与离线主设计 |
| Ramp-up | 待命，预留裕度 | 随拉长增加，稳定性风险上升 |
| Flat-top | 实时反馈，不预设详细离线波形 | 垂直稳定裕度 |

# 8. 本作业推荐的最终简化方案

为了使个人作业工程可落地，推荐采用以下最终方案：

## 8.1 必须生成的波形

| 波形 | 说明 |
|---|---|
| `I_CS1(t)` | CS 第一对模块电流 |
| `I_CS2(t)` | CS 第二对模块电流 |
| `I_CS3(t)` | CS 第三对模块电流 |
| `I_PF1(t)` | PF1 上下对的等效电流 |
| `I_PF2(t)` | PF2 上下对的等效电流 |
| `I_PF3(t)` | PF3 上下对的等效电流 |
| `I_PF4(t)` | PF4 上下对的等效电流 |

## 8.2 可以简化输出的波形

| 波形 | 简化方式 |
|---|---|
| `I_Div1(t)` | 前两阶段为 0 或缓慢过渡，平顶给定小幅修正 |
| `I_Div2(t)` | 前两阶段为 0 或缓慢过渡，平顶给定小幅修正 |
| `I_VS(t)` | 输出基准值和允许控制范围，不生成快速反馈波形 |
| `I_TF(t)` | 给定常值 `B_t` 或对应 TF 电流，不参与优化 |

## 8.3 三阶段的最小可实现逻辑

### Breakdown

- CS：提供击穿电压；
- PF3/PF4：形成击穿零场；
- PF1/PF2：辅助修正局部场；
- Div/VS：不参与；
- TF：背景场。

### Ramp-up

- CS：驱动 `Ip` 上升；
- PF4/PF3：提供随 `Ip` 增大的平衡场，控制位置；
- PF1/PF2：逐步成形，建立拉长、三角形变和 X 点；
- Div：后期进入偏滤器设定；
- VS：只保留裕度；
- TF：背景场。

### Flat-top

- CS：维持电流并检查剩余伏秒；
- PF1/PF2/PF3/PF4：维持目标位形和 X 点；
- Div：调节打击点；
- VS：实时稳定，离线只给裕度；
- TF：背景场。

---

# 9. 一句话总结

本作业中，线圈行为可以简化为：

> CS 负责“把电流拉起来并维持住”，PF3/PF4 负责“把等离子体放在正确位置并建立整体平衡”，PF1/PF2 负责“把等离子体塑造成目标形状”，Div 只在平顶阶段微调打击点，VS 只作为实时稳定裕度，TF 作为固定背景磁场。
