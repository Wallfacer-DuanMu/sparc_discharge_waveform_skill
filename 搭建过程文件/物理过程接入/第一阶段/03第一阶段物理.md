二、升级后的数据传导图（文本版）
text
输入配置 (example.yaml)
    │
    ├── 装置参数: R0, a, B0
    ├── 目标: Ip_seed_MA, breakdown时长
    ├── 线圈约束: I0, Imax, dI/dt_max
    └── 物理参数: M_CS, PF场系数矩阵, 击穿电场阈值
    │
    ▼
Step 1: 生成时间轴 t[0..N] (不变)
    │
    ▼
Step 2: 生成目标 Ip(t) 轨迹（从 0 到 Ip_seed）
    │   - 使用 smoothstep 形状，保证起点终点平滑
    │
    ▼
Step 3: 计算所需的 V_loop(t)
    │   公式: V_loop(t) = L0 * dIp/dt + Rp * Ip(t)
    │   - L0 由 R0, a 算出
    │   - dIp/dt 由数值差分得到
    │
    ▼
Step 4: 用互感反推 CS 总 dI/dt
    │   公式: dI_CS_total/dt = - V_loop(t) / M_CS
    │   (忽略 PF 的 dI/dt 贡献)
    │
    ▼
Step 5: 分配至三个 CS 模块 (CS1, CS2, CS3)
    │   比例 share (可配置，默认 0.3/0.4/0.3)
    │   dI_CSi/dt = share_i * dI_CS_total/dt
    │
    ▼
Step 6: 积分得到 I_CSi(t)
    │   I_CSi(t) = I_CSi(0) + ∫ dI_CSi/dt dt
    │   - 检查每步电流是否在 [I_min, I_max]
    │   - 检查每步 dI/dt 是否超限，若超限则 clip 并记录警告
    │
    ▼
Step 7: 计算 PF 零场预置电流（击穿点）
    │   已知: 击穿点位置 (R_break, Z_break)
    │   场系数矩阵: 每个 PF 线圈在击穿点的 (B_R, B_Z) 每安培贡献
    │   方程组:
    │       Σ (I_PFi * C_Ri) = -B_R_ext   (外部场，如 TF 漏场，暂设0)
    │       Σ (I_PFi * C_Zi) = -B_Z_ext
    │   解出 I_PF3, I_PF4（主力），PF1, PF2 先固定为小值或也参与求解
    │   简化解法: 先设 I_PF1=I_PF2=0，解二元一次方程得 I_PF3, I_PF4
    │
    ▼
Step 8: 生成 PF 波形（从 I0 平滑过渡到目标预置值）
    │   所有 PF 线圈从初始值 I0 线性（或平滑）变化到 Step 7 计算的目标值
    │   检查每步电流限幅、dI/dt 限幅
    │
    ▼
Step 9: Div/VS/TF 保持恒定（或按简化规则）
    │   Div1/Div2 = 初始值 (通常 0)
    │   VS = 基准值（通常 0）
    │   TF = 固定 B0 (不生成电流)
    │
    ▼
Step 10: 合并所有波形，输出逐时刻表格 (rows)
    │
    ▼
Step 11: 物理验证
    │   - 实际零场误差: 用系数矩阵计算击穿点总 B 模，是否 ≤ tolerance
    │   - 实际 V_loop 跟踪: 用 I_CS(t) 反算 V_loop_actual = -M_CS * dI_CS/dt，
    │     与需求 V_loop_needed 比较误差
    │   - 电场 E = V_loop_actual / (2πR0) ≥ 阈值 (如 0.3 V/m)
    │   - CS 伏秒消耗: ∫ V_loop_actual dt ≤ 预算
    │   - 电流/变化率限幅检查
    │
    ▼
输出: 波形CSV + 验证报告 + 末态数据（传给 Ramp-up）
