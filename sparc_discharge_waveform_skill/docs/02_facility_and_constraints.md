# 02 装置结构与约束说明

本文件定义本 Skill 使用的“简化 SPARC 参考装置”。它不是完整工程设计书，而是后续 `Breakdown / Ramp-up / Flat-top` 三阶段线圈电流波形设计的统一设施边界。

本项目采用 `04磁场线圈关系（假设）.md` 的基本分类，但不完全照搬。优化原则是：保留 SPARC 风格的磁体系统结构，同时压缩成适合作业推演和代码实现的功能组。

---

## 1. 简化磁体系统

```text
托卡马克磁体系统（本项目简化版）
├── TF 环向场线圈
│   └── 提供主环向磁场 B_t；作为固定背景场，不设计动态波形
│
└── 极向场与感应驱动系统
    ├── CS 中心螺线管
    │   ├── CS1_U / CS1_L
    │   ├── CS2_U / CS2_L
    │   └── CS3_U / CS3_L
    │       └── 通过电流变化产生环向电压，驱动 Ip 启动、爬升和维持
    │
    ├── PF 主极向场线圈
    │   ├── PF1_U / PF1_L：边界与局部形状控制
    │   ├── PF2_U / PF2_L：拉长、三角形变与 X 点趋势控制
    │   ├── PF3_U / PF3_L：径向/垂直平衡、X 点和上下位形调节
    │   └── PF4_U / PF4_L：击穿零场、整体垂直场和主半径平衡
    │
    └── 辅助线圈
        ├── Div1 / Div2：偏滤器打击点与边缘磁场细调
        └── VS：垂直稳定快速反馈；本项目只保留裕度
```

### 1.1 采用与优化结论

- `TF / CS / PF / Div / VS` 的主分类可以采用。
- `TF` 不作为波形设计对象，只作为 `B0` 背景磁场。
- `CS1-3` 是电流驱动主对象，负责 `Ip` 启动、爬升和维持。
- `PF1-4` 是位形控制主对象，负责击穿零场、平衡、边界、X 点和形状演化。
- `Div` 不承担主升流任务，只在 ramp-up 后段和平顶阶段做偏滤器细调。
- `VS` 属于实时反馈执行器，离线设计中只给基准值和控制裕度。
- `PF3` 不宜只写成“控制垂直位置和底部 X 点”，应表述为参与整体位形、X 点、径向/垂直平衡和上下差分修正。

## 3. SPARC 参考参数

| 参数 | 符号 | 参考值 | 在本项目中的作用 |
|---|---:|---:|---|
| 环向磁场 | `B0` | `12.2 T` | 固定背景磁场 |
| 目标平顶等离子体电流 | `Ip_flat` | `8.7 MA` | ramp-up 终点和平顶目标 |
| 大半径 | `R0` | `1.85 m` | 几何和平衡估算基准 |
| 小半径 | `a` | `0.57 m` | 截面尺寸和边界估算基准 |
| 电子温度 | `Te` | `20 keV` | 平顶背景参数，不直接决定 PF/CS 波形 |
| 电子密度 | `ne` | `4e20 m^-3` | 平顶背景参数，不直接决定 PF/CS 波形 |
| 辅助加热 | `ICRF` | `120 MHz` | ramp-up 后段和平顶背景条件 |

说明：本文件中的参数用于建立量级和约束口径，不代表完整 SPARC 工程数据库。后续代码可在配置文件中覆盖线圈电流上限、变化率、阶段时长等具体数值。

## 4. 建模边界

本项目只做离线候选波形设计，不做完整自由边界平衡求解，也不模拟实时反馈控制。

- 重点生成 `I_CS1(t)`、`I_CS2(t)`、`I_CS3(t)`、`I_PF1(t)`、`I_PF2(t)`、`I_PF3(t)`、`I_PF4(t)`。
- `I_Div1(t)`、`I_Div2(t)` 可简化输出，主要服务平顶偏滤器构型。
- `I_VS(t)` 只输出基准值和裕度范围，不生成高频反馈细节。
- `I_TF(t)` 不参与优化，等效为给定 `B0`。
- 初版先按上下对称线圈组求解，必要时再给 PF 线圈加入小差分修正。

## 5. 上下对称假设

| 线圈对 | 默认关系 | 可放宽情形 |
|---|---|---|
| `CS1_U / CS1_L` | 同组同波形 | 一般不放宽 |
| `CS2_U / CS2_L` | 同组同波形 | 一般不放宽 |
| `CS3_U / CS3_L` | 同组同波形 | 一般不放宽 |
| `PF1_U / PF1_L` | 优先对称 | 平顶形状细调可加入小差分 |
| `PF2_U / PF2_L` | 优先对称 | X 点形成后可加入小差分 |
| `PF3_U / PF3_L` | 优先对称 | ramp-up 后段和平顶可用于上下位形修正 |
| `PF4_U / PF4_L` | 优先对称 | 特殊平衡需求下小差分 |

该假设的目的不是否认真实装置的独立控制能力，而是降低初版求解维度，使波形规划能够稳定落地。

## 6. 三阶段线圈行为约束

| 阶段 | 设施目标 | 主线圈 | 辅助/简化对象 | 关键约束 |
|---|---|---|---|---|
| Breakdown | 形成可靠击穿并建立种子 `Ip` | `CS`、`PF3/PF4` | `PF1/PF2` 辅助；`Div/VS` 不参与；`TF` 背景 | `CS` 提供足够 loop voltage；`PF3/PF4` 形成低 `B_R/B_Z` 击穿区 |
| Ramp-up | `Ip` 升至 `Ip_flat`，同时逐步成形 | `CS`、`PF1-4` | `Div` 后段过渡；`VS` 留裕度；`TF` 背景 | `CS` 伏秒不能提前耗尽；`PF` 随 `Ip` 平滑演化并维持位置/形状 |
| Flat-top | 维持 `Ip_flat`、目标边界、X 点和偏滤器构型 | `CS`、`PF1-4`、`Div` | `VS` 实时反馈裕度；`TF` 背景 | `CS` 保留剩余伏秒；`PF` 接近平稳；`Div` 微调打击点 |

## 7. 主波形与简化波形

### 7.1 必须生成的主波形

| 波形 | 说明 | 主要检查项 |
|---|---|---|
| `I_CS1(t)` | CS 第一对模块电流 | 电流限幅、变化率、伏秒消耗 |
| `I_CS2(t)` | CS 第二对模块电流 | 电流限幅、变化率、伏秒消耗 |
| `I_CS3(t)` | CS 第三对模块电流 | 电流限幅、变化率、伏秒消耗 |
| `I_PF1(t)` | PF1 上下对等效电流 | 电流限幅、平滑性、边界形状趋势 |
| `I_PF2(t)` | PF2 上下对等效电流 | 电流限幅、平滑性、拉长和 X 点趋势 |
| `I_PF3(t)` | PF3 上下对等效电流 | 电流限幅、平衡裕度、必要时上下差分 |
| `I_PF4(t)` | PF4 上下对等效电流 | 电流限幅、击穿零场质量、整体平衡裕度 |

### 7.2 可以简化输出的波形

| 波形 | 简化方式 |
|---|---|
| `I_Div1(t)` / `I_Div2(t)` | breakdown 可设为 0；ramp-up 后段缓慢接近平顶值；flat-top 给定工作点或小幅扫描 |
| `I_VS(t)` | 输出基准值和允许控制范围，不生成快速反馈波形 |
| `I_TF(t)` | 用 `B0 = 12.2 T` 表示背景场，阶段内近似恒定 |

## 8. 硬约束与检查项

### 8.1 电流、电源与伏秒约束

- 每个线圈组电流不得超过配置文件给定的 `I_max`。
- 每个线圈组变化率不得超过配置文件给定的 `dI_dt_max`。
- `CS` 总磁通摆幅必须覆盖 breakdown、ramp-up 和 flat-top 所需伏秒。
- 波形必须连续、平滑，避免非物理阶跃。

### 8.2 磁场与位形约束

- breakdown 阶段击穿区应接近低极向场区域。
- ramp-up 阶段主半径、截面尺寸、拉长比、三角形变和 X 点应平滑演化。
- flat-top 阶段应维持目标边界、X 点和偏滤器入口位形。
- PF 上下差分只能作为后期修正，不能破坏整体平衡。

### 8.3 运行边界

- `TF` 不作为优化变量，默认阶段内恒定。
- `VS` 不参与离线主求解，但必须保留电流和电压裕度。
- `Div` 不承担击穿和主升流任务，只在 ramp-up 后段和平顶阶段发挥作用。
- `ICRF` 加热作为 ramp-up 后段和平顶背景条件，不用于替代 `CS` 感应驱动。

## 9. 默认求解逻辑

本项目采用两条弱耦合主线：

1. 电流驱动线：`目标 Ip(t)` → `所需 loop voltage` → `CS dI/dt` → `CS1/CS2/CS3 波形`。
2. 位形控制线：`目标 R/a/κ/δ/X-point` → `所需 PF 场趋势` → `PF1/PF2/PF3/PF4 波形`。

两条主线先分别生成候选波形，再通过约束检查迭代修正。初版不做完整自由边界平衡求解，只做工程量级、趋势一致性和约束可行性验证。

---

## 10. 最终口径

后续所有阶段文件和代码均采用以下口径：

> `CS` 负责把等离子体电流拉起来并维持住；`PF3/PF4` 负责击穿零场、整体平衡和位置控制；`PF1/PF2` 负责边界成形、拉长和三角形变；`Div` 只做偏滤器打击点细调；`VS` 只作为实时稳定裕度；`TF` 是固定背景环向场。
