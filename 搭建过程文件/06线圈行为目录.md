# 线圈行为目录：简化版

## 1. 合理性检查结论

1. 任务要求重点是完成 **Breakdown — Ramp-up — Flat-top** 三阶段的线圈电流波形设计，`05线圈行为准则.md` 已经按这三阶段展开。
2. 任务核心线圈是 **极向场线圈 PF** 和 **中心螺线管 CS**，文件中已经把 CS 和 PF 作为主波形对象。
3. 题目不要求最优工程定型波形，因此把 TF、Div、VS 做简化处理是合理的。
4. 文件采用“主波形对象 + 简化对象 + 分阶段职责”的方式，适合后续封装成 Skill。

需要坚持的简化原则是：

- **CS 必须保留**：它负责感应电压、等离子体电流启动、爬升和平顶维持。
- **PF1–PF4 必须保留**：它们负责击穿零场、位置控制、形状控制和 X 点/偏滤器位形。
- **TF 简化为背景场**：只给定 `B_t`，不作为主优化对象。
- **Div 弱参与**：主要在平顶阶段调节打击点，前两阶段可置零或缓慢过渡。
- **VS 不做离线快速波形**：只给基准值和控制裕度。

---

## 2. 本任务主要考虑哪些线圈

本任务采用“功能组”而不是完整工程线圈逐个建模。

| 线圈组 | 是否重点设计 | 简化后的角色 |
|---|---:|---|
| CS1 / CS2 / CS3 | 是 | 电流驱动线圈，负责 loop voltage、`I_p` 启动、爬升和平顶维持 |
| PF1 / PF2 | 是 | 成形线圈，负责边界、拉长比、三角形变和 X 点趋势 |
| PF3 / PF4 | 是 | 平衡与位置线圈，负责击穿零场、径向平衡、主半径和 X 点位置 |
| Div1 / Div2 | 弱参与 | 平顶阶段微调偏滤器打击点 |
| VS | 简化 | 不生成快速反馈波形，只输出基准和裕度 |
| TF | 简化 | 提供固定背景环向场，不参与波形优化 |

---

## 3. 哪些线圈是主波形对象

后续 Skill 主要生成以下波形：

```text
I_CS1(t)
I_CS2(t)
I_CS3(t)
I_PF1(t)
I_PF2(t)
I_PF3(t)
I_PF4(t)
```

这些是本项目的核心输出。

可选或简化输出：

```text
I_Div1(t)
I_Div2(t)
I_VS(t)
I_TF(t) 或 B_t
```

其中：

- `I_Div1/2(t)`：前两阶段可为 0 或缓慢过渡，平顶给定工作点；
- `I_VS(t)`：通常为 0 或小偏置，同时给出反馈裕度；
- `I_TF(t)`：通常不生成，只记录背景 `B_t`。

## 4. 三阶段线圈行为总表

| 阶段 | CS1/2/3 | PF1/2 | PF3/4 | Div1/2 | VS | TF |
|---|---|---|---|---|---|---|
| Breakdown 击穿 | 快速变化，产生 loop voltage，触发击穿 | 小幅修正初始场结构 | 预置电流，形成击穿零场区 | 置零或不参与 | 待命，只留裕度 | 固定背景场 |
| Ramp-up 电流爬升 | 持续 swing，驱动 `I_p` 升至目标值 | 逐步成形，建立 `κ、δ、边界` | 随 `I_p` 调整平衡场，控制位置和 X 点趋势 | 后期缓慢接近平顶值 | 待命，检查裕度 | 固定背景场 |
| Flat-top 平顶 | 缓慢变化，维持 `I_p` 并检查剩余伏秒 | 维持目标形状 | 维持整体平衡、X 点和偏滤器入口 | 调节打击点 | 实时反馈对象，离线只给裕度 | 固定背景场 |

## 5. Breakdown 阶段：谁做什么

阶段目标：形成初始等离子体。

| 线圈 | 行为 |
|---|---|
| CS1/2/3 | 从预充磁状态快速变化，提供击穿所需的感应电压 |
| PF3/4 | 击穿前预置，尽量让击穿点附近 `B_R、B_Z` 接近 0 |
| PF1/2 | 给小幅辅助修正，避免初始场线结构过差 |
| Div1/2 | 不参与，通常置零 |
| VS | 不参与离线波形，只留反馈裕度 |
| TF | 提供固定背景环向场 |

简化理解：

```text
CS 负责“点火电压”
PF3/4 负责“制造适合点火的低极向场区”
PF1/2 负责“小修小补”
Div/VS 不主动参与
TF 是背景场
```

---

## 6. Ramp-up 阶段：谁做什么

阶段目标：把等离子体电流升到目标平顶电流，同时逐步形成目标位形。

| 线圈 | 行为 |
|---|---|
| CS1/2/3 | 持续变化，提供 loop voltage，驱动 `I_p(t)` 上升 |
| PF4 | 主要随 `I_p` 增大调整径向平衡和主半径 |
| PF3 | 控制位置、上下位形和 X 点形成趋势 |
| PF1/2 | 逐步建立拉长比、三角形变和边界形状 |
| Div1/2 | 在爬升后段缓慢接近平顶工作点 |
| VS | 不设计快速波形，只检查垂直稳定裕度 |
| TF | 继续作为固定背景场 |

简化理解：

```text
CS 负责“把 Ip 拉上去”
PF3/4 负责“把等离子体放稳”
PF1/2 负责“把等离子体塑形”
Div 后期准备偏滤器
VS 只看有没有裕度
TF 不动
```

---

## 7. Flat-top 阶段：谁做什么

阶段目标：维持目标等离子体电流、目标形状和偏滤器构型。

| 线圈 | 行为 |
|---|---|
| CS1/2/3 | 缓慢变化，维持 `I_p`，检查伏秒是否足够 |
| PF1/2 | 维持边界、拉长比和三角形变 |
| PF3/4 | 维持主半径、整体平衡、X 点和偏滤器入口位形 |
| Div1/2 | 调整打击点位置，可给小幅慢扫描 |
| VS | 作为实时反馈执行器，离线只输出基准和裕度 |
| TF | 固定背景场 |

简化理解：

```text
CS 负责“续航”
PF1/2/3/4 负责“稳住形状和位置”
Div 负责“调打击点”
VS 负责“预留稳定控制能力”
TF 继续不动
```

## 8. 每类线圈的三阶段行为速记

| 线圈 | Breakdown | Ramp-up | Flat-top |
|---|---|---|---|
| CS | 快速 swing，触发击穿 | 大幅平滑 swing，驱动升流 | 慢变，维持电流和伏秒 |
| PF1/2 | 小修正 | 逐步成形 | 维持形状 |
| PF3/4 | 击穿零场和平衡预置 | 位置和平衡主控制 | 维持平衡、X 点和偏滤器入口 |
| Div | 置零 | 后期缓慢接入 | 打击点微调 |
| VS | 待命 | 待命并检查裕度 | 实时反馈，离线只给裕度 |
| TF | 背景常值 | 背景常值 | 背景常值 |

---

## 9. 最小可实现版本

本任务的最小可实现版本只需要：

1. 生成 `I_CS1/2/3(t)`；
2. 生成 `I_PF1/2/3/4(t)`；
3. 对 `I_Div1/2(t)` 给 0、缓慢过渡或平顶工作点；
4. 对 `I_VS(t)` 给 0 或小偏置，并输出裕度；
5. 把 `TF` 作为固定背景参数 `B_t`；
6. 对三阶段分别做电流上限、变化率、CS 伏秒和位形合理性检查。

---

## 10. 一句话总结

本项目的线圈行为可以简化为：

> CS 负责电流驱动，PF3/4 负责位置和平衡，PF1/2 负责位形塑造，Div 只在平顶阶段微调打击点，VS 只保留稳定裕度，TF 作为固定背景磁场。
